# Googly P-Ball

Multiplayer 3D paintball for googly-eyed beans. Up to 8 googlies per lobby (friends and/or computer players), lobby codes and invite links, three arenas (Speedball Field, The Warehouse, Pine Woods), limited ammo with paint crates on the map, cover, crouching, skins, and a Champion Gold skin for whoever won the last match.

Run locally: `npm install && npm start`, then open http://localhost:8000

Tests: `node test/bots.mjs MAP DIFF SECONDS` plays a CPU match against a running server (set `URL=ws://localhost:PORT`).
